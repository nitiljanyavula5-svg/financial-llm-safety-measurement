# What Safety Scores Measure

Reproducibility materials for **What Safety Scores Measure: Evaluation Artifacts in LLM Financial Data Release** (IEEE BigData 2026 LLMs for Finance workshop submission).

The contribution is a four-item reporting checklist, illustrated by a measured decomposition of output interpretation, executed repairs, identifier-aware financial consequences, and certificate admission with correct-release retention. Original prespecified label/advice tests remain inconclusive. Later diagnostics and follow-ups are explicitly separate post-result evidence.

## Get the complete package

Download this repository with **Code → Download ZIP**, or clone it. The complete package is embedded in `restore_reproducibility.py` as a checksummed archive. Restore it with Python 3.12:

```sh
python3 restore_reproducibility.py
python3 -m tarfile -e Finance_LLM_Reproducibility_Code.tar.xz .
cd Finance_LLM_Reproducibility_Code
```

The restoration script writes an archive and checks its SHA256; it executes no study code or provider requests. The archive contains 174 files: generator and prompt/configuration code, restricted executor and checkers, independent numerical fixtures, the C12 manuscript sources and figures, its ten-page PDF, full L2 intervals, admission diagnostic counts, derived outcome flags, stable-ID manifests, source hashes/download scripts, and environment instructions. Read its `README.md` for detailed scope and historical-case reconstruction.

## Offline checks

From the extracted package root, create an environment and install dependencies:

```sh
python3 -m venv .venv
# macOS/Linux:
. .venv/bin/activate
# Windows PowerShell instead:
# .\.venv\Scripts\Activate.ps1
python -m pip install -r reproducibility/requirements.txt
```

Then run:

```sh
python3 reproducibility/verify_package.py
python3 reproducibility/synthetic_demo.py
python3 tests/independent_contract_tests.py
python3 tests/independent_numerical_fixtures.py
python3 reproducibility/recompute_counts.py
python3 reproducibility/recompute_clock_clusters.py
python3 reproducibility/recompute_overlap.py
python3 extensions/whitelist_diagnostic/diagnostic.py
python3 reproducibility/recompute_whitelist.py
```

All nine commands passed after reconstruction in a clean directory. They need no API keys and make no provider calls. Flag recounts reproduce derived counts; they do not substitute for raw-source-to-artifact rescoring.

## C12 diagnostic and configuration limits

The isolated whitelist row adds only `PANEL.payload_version` with the existing `version_id` unit. Original verifier bytecode, binding, old unit rules and scalar equality checks remain unchanged. It recovers 146 correct Luna releases and one Haiku release; unsafe admissions become 98 and 20. Whole arrays and unspecified identifier-unit forms remain separate grammar failures. A separate Fraction implementation agrees on 13,406 strict-valid core responses across all four models.

The fresh Sonnet comparison covers the tested low-effort permissive schema without a think-first instruction; it is not a general ranking of structured outputs. Original scores and locally frozen specifications remain intact. No new provider generation was needed for C12.

## Data and validation scope

Credentials, raw historical return vectors, original source archives and raw provider response text are excluded. Source-data redistribution clearance remains unresolved; API output ownership alone does not settle third-party data rights. Source-download scripts verify archive/member hashes and refuse changed snapshots. Independent historical rescoring additionally requires retained raw inputs and the matching source snapshot. Computational and AI-assisted checks are not represented as human verification.

## Version note

The embedded archive is the immutable C12 reproducibility snapshot. Subsequent manuscript revisions C13–C15 correct a reference title, revise the abstract, and clarify two phrases; they do not change experimental outcomes or analysis code. The submitted paper is the separately verified C15 PDF. The bundled C12 PDF is retained as a historical snapshot, not presented as the final C15 PDF.
